Executive Summary Generator

Upload a standard VAPT Excel (IP / Web / Cert-IN / MitKat layout). One AI pass builds C-suite narrative sections; you get a Word document matching the CyberSmithSECURE Executive Summary structure.

Access: Sign in with your organization account before generating (same session as Report Formats). Expected input:
  • Excel (.xlsx) with the usual columns (asset block, vulnerability block including Observation/Vulnerability Title).
  • Report type selects which sheet name is preferred when multiple sheets exist (IP / Web / Cert-IN); MitKat-style single-sheet workbooks use the first sheet.
  • No POC ZIP required for this report.
Opening the Word file: The report uses a printed Table of Contents (section titles are always visible). Page numbers use Word fields: click Enable Editing if you see Protected View, then press Ctrl+A and F9 to refresh all fields (including page numbers next to each TOC line). This is not controlled by Excel mapping.
Generating executive summary. This usually takes under a minute.
